# servico-entregas-backend
Sistema Back-End em Node.js e MongoDB para gerenciamento de um serviço de entregas. Aplica Programação Orientada a Objetos para manipular as entidades Cliente, Estabelecimento e Pedido. Implementa operações CRUD com o driver nativo, validação de campos obrigatórios, tratamento de exceções e registro de falhas em arquivo de log.
